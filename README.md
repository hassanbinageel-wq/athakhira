# الذخيرة المشرفة v2 · نسخة مستقلّة

تطبيق تعليمي إسلامي للأطفال، يعمل **بدون إنترنت وبدون قاعدة بيانات**. كل شي محلي على جهاز الطفل.

---

## ما الذي تغيّر عن النسخة السابقة؟

- ❌ **لا Supabase** — انتهت أخطاء "Failed to fetch" نهائياً
- ❌ **لا تسجيل دخول** — تعبئة بسيطة أول مرة (اسم + عمر + جنس)
- ❌ **لا لوحة تحكم** — تطبيق واحد بس
- ✅ **يعمل بدون إنترنت** بعد التثبيت
- ✅ **نسخ احتياطي** JSON للنقل بين الأجهزة
- ✅ **قسم لوليّ الأمر** داخل الإعدادات لسماع تسجيلات الطفل

---

## خطوات النشر

### ١. رفع الملفات على GitHub

الطريقة الأسهل: **احذف الملفات القديمة كاملة** وارفع الحزمة الجديدة.

من مستودعك على GitHub:
1. احذف كل شي في `www/js/` القديم
2. احذف `www/index.html`
3. من الحزمة الجديدة، ارفع محتويات `student-app/` كاملة
4. تأكد أن الشخصيات موجودة: `www/assets/characters/boy.png` و `girl.png`

⚠️ **لا حاجة لتعديل أي مفاتيح** — التطبيق ما يحتاج أي مفاتيح بعد الآن.

### ٢. إضافة PDF الكتاب (اختياري)

- ضع نسخة PDF في: `www/assets/book/athakhira.pdf`
- ارفعها إلى GitHub

### ٣. انتظر بناء APK

- GitHub Actions يبني تلقائياً بعد كل push
- ٥-٨ دقائق ← Actions → Artifacts → `athakhira-v2-apk`

## كيف يعمل التطبيق؟

### أول تشغيل
1. الطفل يفتح التطبيق
2. يظهر نموذج: **الاسم، العمر، طفل/طفلة**
3. يضغط "ابدأ الرحلة"
4. يبدأ الفصل الأول مفتوحاً، الباقي مقفول

### الاستخدام اليومي
- الشخصية تحيّي الطفل باسمه
- تظهر رسائل تحفيز أثناء الدروس والاختبارات
- بعد كل درس: صندوق مكافأة → +10 نجوم +30 XP
- عند إتقان اختبار (٩٠٪+): +20 نجمة إضافية
- عند جمع ١٠٠ نجمة: يفتح الفصل التالي 🎉
- عند تجاوز XP معيّن: يترقّى في المستوى (مبتدئ → خبير)

### لوليّ الأمر
- من الأيقونة ⚙️ فوق يمين → "لوليّ الأمر"
- يشوف كل تسجيلات الطفل الصوتية في قسم "فكّر قليلاً"
- يقدر يستمع لكل تسجيل بالضغط ▶️

### النسخ الاحتياطي
- ⚙️ الإعدادات → **حفظ نسخة احتياطية**
- يتنزّل ملف JSON فيه كل شي (التقدّم، النجوم، التسجيلات، الملف الشخصي)
- على جهاز آخر: يختار "استعادة من ملف" ويحمّل الـ JSON

## أسئلة شائعة

**س: هل التطبيق يحتاج إنترنت؟**
ج: لا. بعد التثبيت يعمل ١٠٠٪ بدون إنترنت. الخط فقط يُحمَّل من جوجل أول مرة.

**س: لو غيّر الطفل الجهاز، هل يخسر تقدّمه؟**
ج: لا، يكفي حفظ نسخة احتياطية من الإعدادات ثم استعادتها في الجهاز الجديد.

**س: هل التسجيلات الصوتية آمنة؟**
ج: نعم، تُحفظ محلياً على الجهاز فقط، ما تُرسل لأي خادم.

**س: كم مساحة يأخذ التطبيق؟**
ج: التطبيق نفسه ≈ ٥ ميجا. البيانات المحلية تكبر مع التسجيلات (كل دقيقة تسجيل ≈ ٥٠ ك.ب).

**س: كيف أشارك تقدّم طفلي مع المدرّس؟**
ج: صدّر النسخة الاحتياطية (JSON) وأرسلها. يمكن للمدرس عرضها في تطبيقه (لأن المشروع مفتوح).
